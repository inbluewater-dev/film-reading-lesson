# HWPX 템플릿 출처

이 폴더의 XML 파일은 python-hwpx 6.8.0(https://github.com/airmang/python-hwpx, Apache License 2.0, Copyright 2025-2026 airmang)의
`hwpx/data/Skeleton.hwpx`에서 가져온 빈 문서 뼈대입니다. 앱은 이 뼈대에 글자 모양·문단 모양·테두리를 덧붙이고 본문(section0.xml)을 새로 씁니다.

- "HWPX"는 한글과컴퓨터가 정한 문서 형식입니다. 이 앱은 한글과컴퓨터와 관계없는 독립 구현입니다.
- 본 제품은 한글과컴퓨터의 한글 문서 파일(.hwp) 공개 문서를 참고하여 개발하였습니다.
